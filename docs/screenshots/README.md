# Проверка адаптивных экранов

Снимки получены Playwright из production-сборки на 1440×1100, вертикальном Full HD 1080×1920, 1024×1100, 768×1100 и 390×844. Для каждого размера сохранены главная архива, страница реальной работы и настройки. Отдельные `before/` и `after/` снимки hero, задания и настроек используются в [UX-аудите](../UX-AUDIT.md).

Пересоздать снимки после изменений: `npm run capture:screenshots`. Команда сначала строит production-версию, затем открывает её в Chromium и перезаписывает PNG-файлы.
