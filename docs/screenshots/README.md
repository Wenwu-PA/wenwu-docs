# Проверка адаптивных экранов

Снимки получены Playwright из production-сборки на 1440×1100, вертикальном Full HD 1080×1920, 1024×1100, 768×1100 и 390×844. Для каждого размера сохранены главная архива и страница реальной работы из текущего контента.

Пересоздать снимки после изменений: `npm run capture:screenshots`. Команда сначала строит production-версию, затем открывает её в Chromium и перезаписывает PNG-файлы.
