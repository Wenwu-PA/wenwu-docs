# Аудит `wenwu-docs`

- На момент аудита репозиторий содержит 31 отслеживаемый файл и шесть коммитов.
- Старый сайт построен на MkDocs Material и Python.
- В `mkdocs.yml` настроены поиск, вкладки, таблицы и подсветка кода.
- Единственная содержательная страница — `docs/index.md` с кратким описанием личной базы знаний.
- Остальные 25 страниц разделов пустые и не содержат учебных материалов.
- Навигация старой версии перечисляет программирование, IT TOP, сети, проекты и справочник.
- В репозитории уже есть GitHub Pages workflow с раздельными build и deploy jobs.
- Стандартные Pages actions и разделение прав можно переиспользовать.
- Старый workflow собирает каталог `site` через MkDocs и реагирует только на push в `main`.
- Старый `requirements.txt` не нужен Vite-проекту.
- Полезный текст вводной страницы перенесён в README и основу нового интерфейса.
- Пустые страницы MkDocs и старый конфиг не нужны динамическому архиву; список удаления зафиксирован в Git diff.
- Рекомендованные изменения: оставить React/Vite для архива, а GitHub Pages собирать из текущего контента при каждом запуске.
