# Wenwu Docs

Личная база знаний по программированию, колледжу, сетям и собственным проектам.

## Разделы

### 💻 Программирование

Алгоритмы, функции-помощники, структуры данных и заметки по языкам программирования.

### 🎓 Колледж

Домашние и практические работы, решения задач и полезные материалы.

### 🌐 Сети

Практический опыт настройки роутеров, OpenWrt, VPN, DNS, маршрутизации и диагностики сетевых проблем.

### 🛠 Проекты

Документация собственных проектов и полезные ссылки на исходный код.

### 📚 Справочник

Ссылки на программы, прошивки, документацию и другие полезные ресурсы.
