# План реализации

1. Сохранить аудит старого MkDocs-проекта и создать каркас Vite, React и TypeScript.
2. Перенести токены Red Index, локальные IBM Plex Sans/Mono и знак `[W]` из макета.
3. Собрать манифест из реального дерева Git с фильтрами служебных и сборочных каталогов.
4. Проверять форму каждого узла манифеста через Zod.
5. Построить поисковый индекс на этапе сборки и загружать его по запросу.
6. Реализовать адаптивную главную архива и навигацию по темам.
7. Добавить дерево исходных папок и файлов с постоянными hash-ссылками.
8. Реализовать просмотр кода, Markdown, изображений и PDF.
9. Добавить локальные черновики, diff, скачивание и ссылки GitHub/github.dev.
10. Добавить шаблон записи, ZIP-экспорт и локальный журнал статусов дневника.
11. Перевести GitHub Actions на сборку и деплой GitHub Pages с расписанием и dispatch.
12. Подготовить HOWTO, инструкции автосборки, проверки и снимки экранов.
