# Допущения

- Текущая локальная копия `wenwu-docs` работает отдельно от `IT-TOP_academy`; контентный репозиторий не изменяется.
- Локальный `content-src/` синхронизируется с публичной веткой `main`; Actions также забирает эту ветку без токена и с полной Git-историей.
- Дерево строится из `git ls-files`; правила `.gitignore` применяются и к уже отслеживаемым файлам. Пустые папки Git не хранит. Папки `.vscode`, `.vs`, `.idea`, `bin`, `obj`, `build`, `packages` и другие каталоги среды/сборки исключены, как и расширения `exe`, `obj`, `pdb`, `ilk`.
- Все остальные отслеживаемые файлы репозитория включены в дерево.
- Текстовые файлы, изображения и PDF до 1 MiB копируются в сайт; офисные файлы до 10 MiB сохраняются для скачивания. DOCX/PPTX/XLSX/CSV преобразуются при сборке; PDF ищется и рендерится через лениво загружаемый PDF.js. При ошибке конвертации остаются метаданные и ссылка на оригинал.
- Изображения внутри DOCX встраиваются в HTML, если они занимают не больше примерно 300 KiB.
- Счётчик hero задан как `course: 2` в `site.config.yml`; это номер курса из макета, а не вычисленный счётчик папок.
- Предметы сопоставляются с папками по нормализованным алиасам `topics.config.yml`; новые предметные папки получают собственный раздел и предупреждение сборки.
- Датой задания считается дата в папке непосредственно под предметом, формат даты приводится к `ДД.ММ.ГГГГ`; внутренние каталоги одного задания не становятся отдельными заданиями.
- README в папке работы служит источником условия; `.archive.yml` рядом с ним может задавать `title`, `topic`, `tags`, `status`, `statement` и `method`.
- Загрузка работы в дневник автоматизируется только через копирование текста и скачивание ZIP: доступ к личному порталу и его API не предоставлен.
- Черновики и журнал дневника хранятся в localStorage текущего браузера, без синхронизации.
- Все адаптивные состояния, кроме экрана 390 px, выведены из desktop-макета; отдельные Figma-фреймы 1024/768 не предоставлены.
- При отсутствии IBM Plex на локальной машине браузер использует системный sans/monospace fallback; production-шрифты локально упакованы через npm.
- Рабочий сайт остаётся в существующем репозитории `wenwu-docs`; новый репозиторий не создаётся. `IT-TOP_academy` остаётся источником контента и не меняется этим проектом.
- Автоматический workflow видит опубликованный `main` источника. Незафиксированные локальные изменения исходного репозитория не появятся на сайте, пока их не отправят в GitHub.
