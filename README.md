# Wenwu · Учебный архив

Неофициальный личный архив учебных работ. Он показывает исходное дерево `Wenwu-PA/IT-TOP_academy`, группирует работы по предметам и открывает предпросмотр без копирования контента вручную.

Сайт: <https://wenwu-pa.github.io/wenwu-docs/>
Источник материалов: <https://github.com/Wenwu-PA/IT-TOP_academy>

## Локальный запуск

Требуется Node.js 20 или новее и Git.

```sh
npm ci
npm run content:sync
npm run dev
```

`npm run content:sync` загружает публичный репозиторий в игнорируемую `content-src/`. Сборка читает из неё файлы и историю Git. Большие файлы и бинарники остаются доступны по ссылкам GitHub.

```sh
npm run lint
npm run typecheck
npm test
npm run test:e2e
npm run build
npm run capture:screenshots
```

## Автосборка

GitHub Actions клонирует публичный контентный репозиторий при публикации сайта, ручном запуске, событии `repository_dispatch` и каждые 30 минут. Повторную публикацию того же SHA workflow пропускает. Чтение публичного репозитория не требует PAT; настройка мгновенного dispatch описана в [docs/AUTO-REBUILD.md](docs/AUTO-REBUILD.md). Структура сборки, темы и локальные заметки указаны в [docs/HOWTO.md](docs/HOWTO.md).

Архив не связан с порталом дневника и не отправляет работы автоматически: текст можно скопировать, а файлы скачать ZIP-архивом. Черновики, журнал отправок и пользовательский шаблон остаются в браузере.
